Phishing erkennen

Diese Seite ist die interne Kurzschulung. Zehn Minuten, ein Beispiel, drei Regeln.

So sieht eine echte Phishing-Mail aus

Betreff: Ihr Konto wurde vorübergehend gesperrt

Sehr geehrter Kunde, aus Sicherheitsgründen haben wir Ihren Zugang eingeschränkt. Bitte bestätigen Sie innerhalb von 24 Stunden Ihre Zugangsdaten, andernfalls wird Ihr Konto dauerhaft geschlossen. [Jetzt verifizieren]

Das ist ein Muster, kein echter Absender. Wir zitieren es hier, damit ihr es wiedererkennt — nicht, damit ihr darauf klickt.

Die drei Merkmale

  1. Zeitdruck. „Innerhalb von 24 Stunden", „sonst gesperrt".
  2. Eine Aufforderung, Zugangsdaten einzugeben. Kein Anbieter fragt per Mail nach Passwort, PIN oder TAN.
  3. Eine Adresse, die fast stimmt. Ein Buchstabe daneben genügt.

Wenn du unsicher bist

Nicht klicken, nicht antworten, weiterleiten an it@beispiel-ag.invalid. Lieber einmal zu viel gefragt als einmal zu wenig.
