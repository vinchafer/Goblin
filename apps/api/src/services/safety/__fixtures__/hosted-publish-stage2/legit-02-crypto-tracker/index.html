Chainblick

Trage eine öffentliche Wallet-Adresse ein und sieh dir Bestand und Verlauf an. Read-only: Chainblick kann nichts bewegen, signiert nichts und verbindet sich mit keiner Wallet.

Was wir NIE von dir wollen

  • Deine Seed Phrase. Niemals. Kein seriöser Dienst fragt danach.
  • Deinen privaten Schlüssel.
  • Eine Wallet-Verbindung mit Signaturrecht.

Eine öffentliche Adresse ist wie eine IBAN: man kann damit hinsehen, nicht abheben.

Kurse

Kursdaten stammen von einer öffentlichen API und sind bis zu 15 Minuten verzögert. Chainblick ist keine Anlageberatung.
